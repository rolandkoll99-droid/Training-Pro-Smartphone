ReadMe Datei für PC/Monitor! 


Neue Eingabe bei Stockpunkte:
Die 0 muss bei der Mannschaft eingeben werden welche keine Stockpunkte erreicht hat
Bei der Mannschaft welche Stockpunkte erzielt hat müssen die Punkte (1-4) eingeben werden.
Erst dann geht es zur nächsten Kehre!
 

So funktioniert es:

    PC-Bildschirm (Steuerung): Volle Funktionalität mit Buttons, Punkteeingabe, Einstellungen.

    TV/Monitor (Zuschauermodus): Nur die Ergebnisanzeige (Teamnamen, Punkte, Siege, aktuelle Kehre, Timer) – perfekt für die Zuschauer.

    Über die Tastatur können Sie mit F11 den Vollbildmodus umschalten. Zusätzlich gibt es einen kleinen Button in der Steuerungsansicht, um das Zuschauer-Fenster zu öffnen.

Einfache Anwendung:

    Datei auf dem PC öffnen (Chrome/Edge empfohlen).

    Zweiten Monitor/TV anschließen.

    Das Zuschauer-Fenster auf den zweiten Bildschirm ziehen und per F11 in Vollbild setzen.

    Auf dem Hauptbildschirm die Steuerung bedienen – alle Änderungen werden live auf dem TV angezeigt.

Datei im Browser öffnen (Chrome/Edge empfohlen).

Den zweiten Monitor/TV anschließen.

Klick auf „📺 Zuschauer-Monitor öffnen“ → ein neues Fenster öffnet sich.

Dieses Fenster auf den zweiten Bildschirm ziehen und mit F11 in den Vollbildmodus versetzen.

Das ursprüngliche Fenster (Steuerung) bleibt bedienbar – alle Änderungen werden live im Zuschauer-Fenster aktualisiert.
